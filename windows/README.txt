HEAVENLY MANDATE - PIXEL KINGDOM 16.0

1. Download the current ZIP from GitHub, then extract the entire archive.
2. Double-click Play.bat or open Thien-Menh.html with Chrome or Edge.
   Direct HTML play needs no installation, account or internet connection.
3. Optional: run Serve-with-Python.bat if Python 3 is installed.
   Or run: python serve_game.py --no-browser --port 8765
   Open the printed localhost address. Keep the terminal open while playing.
4. Back up progress through Settings > Save Management > Export Save.
   Import that JSON backup when changing browser, device, port or launch method.
   Private/incognito windows do not reliably retain progress.
5. Use + and - or the mouse wheel to zoom the map; drag to pan.
   Phones support pinch zoom and use the landscape game layout.
6. The player game contains no Studio or debug currency grants. Developer tools
   are distributed in the separate Heavenly-Mandate-DevTools.zip package.

This package is the solo preview. Shared online accounts require a separately
hosted game server; local progress is not uploaded automatically. The game is
not a signed App Store or Google Play release. Native Bluetooth requires the
compatible native app and cannot run in Safari.

Keep only one copy of this package when testing an update, and keep your save
backup in a separate safe folder. Never delete your backup to update the game.
