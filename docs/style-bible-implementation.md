# Golden Warring Kingdoms — Style Bible implementation

Source: the project owner's “Style Bible & Spec Godot — Thiên Mệnh · Pixel Kingdom”, version 1.0, 9 November 2026. This update applies its visual direction to the existing JavaScript game. It does not execute the document's separate seven-stage Godot migration plan.

## Canonical resources

- `config/style-bible.json`: exactly 47 colors, named shade ramps, element and rarity semantics, the reference viewport and frame timings.
- `style-palette.mjs`, `style-bible.css`, `art/palette.hex`, `art/palette.png`: generated by `node tools/sync-style-bible.mjs`; normal dev and release builds run this synchronization.
- `style-bible.template.css`: shared UI rules. Ink and Royal Blue surfaces, Parchment text, Gold primary actions, Crimson danger actions, Ink disabled actions, hard pixel borders and upper-left highlights replace the old jade theme.
- VT323: locally embedded pixel font, verified to contain ạ, ế, ữ, ơ, ư and đ. The original font and SIL OFL license are included. There is no external font request.

## Renderer

Existing original PNG atlases are preserved, including their sprite cells and saved identifiers. Visible sprite/background assets are palette-mapped lazily at runtime, using a 5-bit RGB lookup texture whose entries are approved colors. Alpha is thresholded to 0 or 255. A yielding CPU fallback provides the same color/alpha rules if WebGL is unavailable. If a native/custom URL scheme blocks both GPU texture access and canvas readback, the renderer preserves the original playable picture and marks `restricted-source` instead of crashing; that platform needs native-origin testing before claiming palette compliance. Terrain uses a more restrained subset of the same palette so it does not compete with units. Source atlases are not falsely certified as hand-cleaned 47-color exports.

The main city/region/combat canvas has a final palette pass at a 360-pixel native height and a 640–800 native width. Its picture is presented at an integer physical-pixel scale, with Ink margins. Camera input and floating-number coordinates use the inverse/forward presentation mapping, preserving zoom, drag and hit testing. The online room map keeps its existing canvas geometry while sharing the palette pass. The current DOM HUD and menus retain their existing responsive layout; their CSS and artwork use the new palette, but browser text anti-aliasing/compositing can still create intermediate screenshot colors. A whole-screen Godot CanvasLayer palette shader and a wholly native 640–800×360 UI remain separate migration work.

The Settings → Golden Style Lineup preview contains five correctly matched elemental heroes at 64 pixels, a 192-pixel world boss, three 32-pixel terrain tiles, five distinct elemental effect motifs and the shared panel/button language. It is a review aid, not automatic aesthetic approval. Its canvas uses integer scaling on desktop and rotated phone layouts.

## Semantic mapping

| Game grade | Style category | Frame |
| --- | --- | --- |
| D / C | Common | Silver 2 / 3 |
| B / A | Rare | Royal Blue 2 / 3 |
| S / SS | Epic | Void 2 / 3 |
| SSS | Legendary | Gold 3 |
| SSR | Mythic | Crimson 3 with Gold outer trim |

The grade text remains Parchment. Element colors belong to element badges and skill effects: Metal Silver, Wood Green, Water Royal Blue, Fire Crimson and Earth Earth. Existing Light/Dark specialties use Gold/Void without changing their ownership or combat coefficients. Skill texture frames are recolored into the caster's element ramp instead of borrowing grade colors or arbitrary hues. High-rarity title corners use a four-step sparkle.

## Animation and remaining acceptance

Idle timing now uses an unequal four-frame table; reference attack/skill/walk/hit durations are stored separately for future asset exports. Existing four-frame walking atlases were not relabeled as six new drawings. Feedback now uses a 34 ms hit flash, integer 120 ms recoil, short visual-only hit-stop and capped integer camera offsets. Simulation and UI continue while the battle picture is held. Reduced Motion suppresses these movements. No combat damage timing, reward or save rule was changed.

Manual cleanup of every silhouette, upper-left lighting, per-object three-to-five-shade budgets, sprite dimensions divisible by 16 and full six-to-ten-frame action sets still require an asset-production/Godot phase. The existing high-resolution atlas layout is intentionally preserved during this style-only change. No Godot port, iOS hardware result or low-end device performance certification is claimed.
